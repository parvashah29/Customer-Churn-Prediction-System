# Customer Churn Dataset

This directory should contain the customer churn dataset used by the application.

## Dataset Information

The application expects the Telco Customer Churn dataset, which can be downloaded from:
- [Kaggle: Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## Setup Instructions

1. Download the dataset from Kaggle
2. Place the CSV file in this directory with one of these names:
   - `customer_churn.csv`
   - `WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Dataset Format

The dataset should contain the following columns:
- customerID
- gender
- SeniorCitizen
- Partner
- Dependents
- tenure
- PhoneService
- MultipleLines
- InternetService
- OnlineSecurity
- OnlineBackup
- DeviceProtection
- TechSupport
- StreamingTV
- StreamingMovies
- Contract
- PaperlessBilling
- PaymentMethod
- MonthlyCharges
- TotalCharges
- Churn

## Troubleshooting

If you encounter any issues:
1. Ensure the CSV file is in the correct location
2. Verify the file name matches one of the expected names
3. Check that the dataset contains all required columns
4. Make sure the file is not corrupted or empty
